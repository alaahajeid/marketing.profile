# Ala'a AlHaj Eid — Marketing Portfolio

Premium static portfolio redesign for GitHub Pages.

## Structure

- `index.html` — semantic single-page portfolio and expandable case studies
- `styles.css` — responsive editorial design system
- `script.js` — navigation, scroll reveals, case-study expansion
- `assets/favicon.svg` — favicon
- `assets/og-card.png` — social sharing image
- `assets/projects/*/README.md` — exact folders for future owned project imagery

## GitHub Pages

This project is intentionally framework-free and uses relative asset paths, so it can continue publishing from the repository root on GitHub Pages.

## Recommended branch workflow

```bash
git checkout -b portfolio-redesign-v1
# copy these files into the repository root
git add .
git commit -m "Redesign marketing portfolio"
git push -u origin portfolio-redesign-v1
```

Do not merge into `main` until the redesign is reviewed and approved.

## Content guardrail

No ROI, revenue, campaign reach, budget, conversion or growth claims should be added without approval and a public/verified source.
